### Featured Repositories

* **[bacterial-antibiotic-prediction](https://github.com/MarianaLealCardin/bacterial-antibiotic-prediction)** — *MSc Thesis (2026)*  
  End-to-end bioinformatics and machine learning pipeline (`Python`, `scikit-learn`, `Abricate`, `CARD`) predicting antimicrobial resistance across 20 drug classes and evolutionary lineages (MLST) from 1,500 complete bacterial genomes (*S. aureus*, *K. pneumoniae*, *E. coli*) using canonical k-mer frequencies.

* **[giant-earthworms-phylogenomics](https://github.com/MarianaLealCardin/giant-earthworms-phylogenomics)** — *Leal-Cardín et al., 2026 (Zool. J. Linn. Soc.)*  
  Reproducible SLURM/BASH phylogenomic inference pipeline (`MAFFT`, `trimAl`, `IQ-TREE 3`, `AMAS`, `ASTER/ASTRAL`) across 660 loci and 72 species, implementing both summary coalescent and partitioned concatenation approaches.

* **[Gene-expression-Midas-cichlid](https://github.com/MarianaLealCardin/Gene-expression-Midas-cichlid)** — *PhD Thesis Supplementary Data*  
  Differential gene expression (DEG) result tables across 20 lake and morphotype comparisons in Nicaraguan Midas cichlids (*Amphilophus* spp.).
